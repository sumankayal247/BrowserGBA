## mGBA (emulator core) — MPL-2.0

The emulator is [mGBA](https://mgba.io/) by endrift and contributors, used
through the WebAssembly port in
[`@thenick775/mgba-wasm`](https://github.com/thenick775/mgba) (branch
`feature/wasm`, version 2.5.1), itself derived from `mgba-emu/mgba`.

- License: Mozilla Public License 2.0. A copy ships with the vendored files as
  `public/mgba/NOTICE.md`.
- **The core is used unmodified.** `scripts/sync-core.mjs` copies `mgba.js` and
  `mgba.wasm` byte-for-byte out of `node_modules/@thenick775/mgba-wasm` into
  `public/mgba/` at build time, together with a manifest recording the version and
  hashes. Nothing in `public/mgba/` is hand-edited.
- Because the files are unmodified, no source-distribution obligation is triggered
  beyond keeping the notice and the manifest; the corresponding source is the
  upstream project at the tag/version recorded in `core-manifest.json`.
- The core is loaded at runtime from `/mgba/mgba.js`. It is deliberately *not*
  processed by the bundler, because its pthread worker resolves
  `new URL('mgba.js', import.meta.url)`.

## What is deliberately not included

- **No ROMs.** BrowserGBA ships no game images and no download links. The only ROM
  in the repository is `fixtures/test-rom.gba`, generated by
  `tools/make-test-rom.mjs` from hand-written, original ARM code written for this
  project (MIT, same as this repository). It is not a game, contains no third-party
  code, and is regenerated on demand rather than committed.
- **No BIOS.** The core runs with its built-in high-level BIOS emulation, which is
  why the fixture's Nintendo-logo area is intentionally left blank: it is not
  reproduced anywhere in this project.
- **No copyrighted artwork.** Icons are generated by `tools/make-icons.mjs` as
  original pixel art.
- **No cheat databases.** Cheat codes are typed in by the user, stored locally, and
  never bundled or fetched.
- **No analytics, telemetry or remote metadata.** The app makes no network requests
  beyond its own origin.
